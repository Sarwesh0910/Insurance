# Insurance Claims Processing Platform

A cloud-native insurance application demonstrating DevOps and Platform Engineering practices.

## Features

- Policy Management
- Claims Registration
- Claims Approval Workflow
- Notification Service
- Audit Logging
- CI/CD Automation
- Kubernetes Deployment
- Infrastructure as Code
- Monitoring and Alerting

## Tech Stack

- AWS
- Kubernetes
- Docker
- Jenkins
- Terraform
- GitHub Actions
- Prometheus
- Grafana

## Architecture

Policy Service -> Claims Service -> Notification Service -> Audit Service

All services are containerized and deployed on Kubernetes.
